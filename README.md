# IOT_SMART_HOME

Smart Home IoT project (HIT 2025)

## Components
- 3 Emulators: Temperature sensor, Button, Relay
- Data Manager: subscribes to MQTT topics + writes to DB
- GUI: shows sensor values and alarm status

## How to run (later)
1. Install requirements: `pip install -r requirements.txt`
2. Run Data Manager
3. Run emulators
4. Run GUI
